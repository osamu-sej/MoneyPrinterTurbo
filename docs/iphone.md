# iPhoneからMoneyPrinterTurboを使う

1. Mac miniの `~/mpt/home/public-access-link.txt` にある専用リンクを、自分のiPhoneへ安全に転送します。リンクにはアクセスキーが含まれるので、他人へ共有しないでください。
2. iPhoneのSafariでそのリンクを最初に一度開きます。以後は [MoneyPrinterTurbo](https://mac-mini.tail347817.ts.net:8443/) を直接開けます。iPhoneへのTailscaleアプリ導入やログイン操作は不要です。
3. 自宅のWi-Fiを切ってモバイル通信でも開けることを確認します。よく使う場合はSafariの共有メニューから「ホーム画面に追加」を選びます。操作は[Appleの手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)を参照してください。

Mac miniは電源を入れ、ユーザーがログインした状態にしておきます。SafariのCookieを消した場合や別のブラウザを使う場合は、専用リンクをもう一度開いてください。

この公開URLは本人用のCookieで保護されています。Mac miniには従来のtailnet限定URLも残しています。iPhone本体でのSafari表示と動画のダウンロードは実機で確認してください。
